## English

Prefix rules editor: show an error with a Retry action when reloading the rules fails (e.g. root was lost) instead of an endless spinner, and number each rule's remove button for screen readers.

## Русский

Редактор правил префиксов: показывать ошибку с кнопкой «Повторить» при сбое перезагрузки правил (например, при потере root) вместо бесконечного индикатора, а также называть кнопку удаления каждого правила с её номером для программ чтения с экрана.
