## English

IPv4 rewrite fakes no longer need to stay inside the rule prefix — any unicast address is accepted (e.g. a proxy exit IP synced by the control panel); editors still steer manual entries to the CGNAT range

## Русский

Подменённый IPv4-адрес больше не обязан лежать внутри префикса правила — принимается любой юникаст-адрес (например, IP выхода прокси); редактор по-прежнему подсказывает диапазон CGNAT для ручного ввода
